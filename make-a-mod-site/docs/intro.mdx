# Tutorial Intro


## Getting Started

:::info
No previous experience with coding is required to follow this guide!
:::
### What you'll need

- **Balatro**:
  - A copy of the game so you are able to mod it.

- **Visual Studio Code** *or any code editor of your choice [supported by Hackatime](https://hackatime.hackclub.com/docs)*:
  - You can download it from [here](https://code.visualstudio.com/download). It's a free and open-source code editor developed by Microsoft, and it's widely used in the programming community.
  We'll use it in the guide but if you prefer another one, you are free to use it.

- **Hackatime**:
  - [Hackatime](https://hackatime.hackclub.com/) is a tool we use to track the time spent in the editor. You must create a Hackatime account and use it while working on your mod. 
  If you don't, you won't be able to claim any prices. Read here how to set it up
