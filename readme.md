# Make A Mod: Balatro
- Part of a YSWS series that will include several guides for beginners to learn how to mod some easy-to-mod games. 
- The first game will be Balatro since it's a fairly known and really easy to mod (uses lua). The idea for other games to be like this.
"Create a Joker, get a deck" (Jokers are a core part of the game, akin to powerups in other games)

- These guides will include a simple step by step guide on how to implement something (i.e. adding a new Joker to Balatro) and then list some ideas to \
develop and link more resources to mod

- The goal of this YSWS is to make each mod a project the creator can be proud of.

## Submit a mod
ehs == estimated hours spent
- Beginners will follow the guide, create their own mod and submit it through a form. From here, several things may happen:
  1. Fraudulent project (ehs N/A) - projects either plagiarized, fully AI-generated or inflated hackatime - The project gets fully rejected, no prize is given, normal fraud flow.
  1. Incomplete project (ehs 2-4) - projects that have only followed the guide without elaborating on a idea devised by the creator. - The project gets accepted as incomplete and the creator gets encouraged to keep working on it and develop their own idea. A [half prize] prize is given.
  2. Complete project (ehs 4-7) - A project that has made significant changes to be recognizable as a standalone mod, not just a "tutorial project" and is properly shipped. - The creator gets the [full prize] (+ [half prize] if the creator hasn't gone through the "incomplete project" phase
  ) and the project gets added to the gallery
